# IndyKite

> IndyKite is the runtime control layer for agentic AI: it applies trust, context, and runtime control across enterprise data so autonomous AI agents can act securely. The platform continuously injects live signals — identity, provenance, freshness, sensitivity, and compliance status — into AI actions and access decisions at the moment they occur, on top of an Identity Knowledge Graph (IKG) with Knowledge-Based Access Control (KBAC), AuthZEN authorization, ContX IQ contextual queries, and a hosted MCP server.

## APIs

- [IndyKite REST API (OpenAPI 3.2.0)](https://openapi.indykite.com/v1/openapi.yaml): Capture, DataSchema, ContX IQ, AuthZEN/KBAC authorization, and Entity Matching. Servers: https://eu.api.indykite.com, https://us.api.indykite.com
- [IndyKite Config REST API (OpenAPI 3.2.0)](https://openapi.indykite.com/v1/config.yaml): CRUD for Organizations, Projects, Applications, Application Agents, Service Accounts, Authorization Policies, Knowledge Queries, Entity Matching, Event Sinks, External Data Resolvers, MCP Servers, Token Introspect, Trust Score. Servers: https://eu.api.indykite.com/configs/v1, https://us.api.indykite.com/configs/v1
